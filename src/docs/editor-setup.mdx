## Поддержка синтаксиса

Tailwind CSS использует пользовательский синтаксис CSS, такой как `@theme`, `@variant` и `@source` и в некоторых редакторах это может вызвать предупреждения или ошибки, где эти правила не распознаются.

Если вы используете VS Code, наш официальный плагин [Tailwind CSS IntelliSense](https://marketplace.visualstudio.com/items?itemName=bradlc.vscode-tailwindcss) включает в себя специальный режим языка Tailwind CSS, который поддерживает все пользовательские at-rules и функции, которые использует Tailwind.

В некоторых случаях вам может потребоваться отключить встроенную проверку/валидацию CSS в вашем редакторе, если он очень строг к синтаксису, который он ожидает в ваших CSS-файлах.

## Zed

[Zed](https://zed.dev/?utm_source=tailwind) — это быстрый, современный код-редактор, разработанный с нуля для передовых рабочих процессов, включая агентское редактирование с AI. Он имеет встроенную поддержку автозаполнения Tailwind CSS, линтинга и предварительного просмотра при наведении, без необходимости установки и настройки отдельного расширения. Он также тесно интегрируется с Prettier, поэтому наш официальный [плагин Prettier](https://github.com/tailwindlabs/prettier-plugin-tailwindcss) без проблем работает в Zed после установки.

## IntelliSense for VS Code

Официальное расширение [Tailwind CSS IntelliSense](https://marketplace.visualstudio.com/items?itemName=bradlc.vscode-tailwindcss) для Visual Studio Code улучшает опыт разработки с Tailwind, предоставляя пользователям расширенные функции, такие как автозаполнение, подсветка синтаксиса и линтинг.

<img
  src={require("./img/intellisense.png").default.src}
  alt="Tailwind CSS IntelliSense расширение для Visual Studio Code"
  width={1344}
  height={672}
  className="rounded-lg"
/>

- **Автодополнение** — предоставление интеллектуальных предложений для утилитарных классов, а также [CSS-функций и директив](/docs/functions-and-directives).
- **Линтинг** — выделение ошибок и потенциальных багов как в вашем CSS, так и в разметке.
- **Превью при наведении** — раскрытие полного CSS для утилитарных классов при наведении на них.
- **Подсветка синтаксиса** — так что функции Tailwind, которые используют пользовательский синтаксис CSS, выделяются правильно.

Узнайте больше о проекте [на GitHub](https://github.com/tailwindcss/intellisense) или [добавьте его в Visual Studio Code](vscode:extension/bradlc.vscode-tailwindcss), чтобы начать прямо сейчас.

## Сортировка классов с помощью Prettier

Мы поддерживаем официальный [плагин Prettier](https://github.com/tailwindlabs/prettier-plugin-tailwindcss) для Tailwind CSS, который автоматически сортирует ваши классы в соответствии с нашим [рекомендуемым порядком классов](/blog/automatic-class-sorting-with-prettier#how-classes-are-sorted).

<img src={require("./img/prettier-banner.jpg").default.src} alt="" width={2400} height={819} className="rounded-lg" />

Это работает бесшовно с пользовательскими конфигурациями Tailwind, и поскольку это просто плагин Prettier, он работает везде, где работает Prettier - включая каждый популярный редактор и IDE, конечно, и в командной строке.

{/* prettier-ignore */}
```html
<!-- [!code filename:HTML] -->
<!-- До -->
<button class="text-white px-4 sm:px-8 py-2 sm:py-3 bg-sky-700 hover:bg-sky-800">Отправить</button>

<!-- После -->
<button class="bg-sky-700 px-4 py-2 text-white hover:bg-sky-800 sm:px-8 sm:py-3">Отправить</button>
```

Узнайте больше о плагине [на GitHub](https://github.com/tailwindlabs/prettier-plugin-tailwindcss), чтобы узнать больше и начать работу.
